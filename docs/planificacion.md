# Plan de trabajo

## Objetivo

Desarrollar y evaluar un asistente para localizar evidencia de riesgos y salvaguardas de proyectos en Galápagos. La decisión de financiamiento permanece en el especialista. Las metas vigentes se encuentran en decisiones_vigentes.md.

## Avance y próximas etapas

| Etapa | Estado | Criterio de cierre |
|---|---|---|
| Comparación documental | Primera revisión completada | Diferencias registradas y referencia vigente identificada |
| EDA reproducible | Implementado sobre ZIP local | 56 documentos, 26 pares y seis figuras reproducibles |
| Semana 3 | Diseño experimental pendiente | Tarea, etiquetas y correspondencia con rúbrica resueltas |
| Recuperación BM25 y E5 | BM25 implementado; E5 y evaluación pendientes | Comparación sobre consultas y relevancia verificadas |
| Web | Consulta normativa local implementada; análisis de propuestas pendiente | Interfaz conectada al sistema y manejo de errores probado |
| Optimización | Pendiente | Experimentos y comparación real antes/después |
| Evaluación final | Pendiente | Prueba reservada, métricas y limitaciones documentadas |
| Entrega y videos | Pendiente | Repositorio ejecutable, documentos y dos videos accesibles |

No hay fechas finales verificadas en los enunciados disponibles. No fijar un calendario vencido como compromiso nuevo.

## Riesgos y dependencias

La semana 3 exige curvas de entrenamiento, mientras el diseño actual utiliza modelos preentrenados. Resolver esa diferencia antes de entrenar. Etiquetas de relevancia y revisión del especialista son dependencias reales. El presupuesto de USD 200 requiere registro de gastos; el EDA no estima consumo del sistema completo.

Mantener fuentes privadas fuera de GitHub y resultados de evaluación separados de las metas. El diseño web puede avanzar con ejemplos claramente identificados, pero no debe presentarse como sistema funcional hasta conectarlo y probarlo.
